# Contributing to Minecraft AntiServerClose

Project created and maintained by **[iAlturki](https://github.com/iAlturki)**.

For bugs, include Minecraft/Fabric/Java versions, Linux architecture, whether the native diagnostic passed, and precise reproduction steps. Share short sanitized errors; never post an authentication cache, device code, full server log, world, or host export.

For code changes, run the source-build checks in [docs/BUILD.md](docs/BUILD.md). A new host/version compatibility claim needs a real idle test and successful player join, with dates and limitations recorded. Do not claim that this software is allowed by a provider without evidence.

Keep existing copyright notices, **iAlturki** project credits, GPL terms, and upstream attribution. Changes must use a GPL-v3-compatible license. Do not include Microsoft credentials or host-specific personal defaults.
